📌 Introduction

FlowTheme is a modern, highly customizable, and performance-optimized Shopify 2.0 theme designed for multi-niche e-commerce stores. Built with Shopify's Online Store 2.0 architecture, it supports JSON templates, app blocks, and dynamic data sources out of the box.

📥 Installation Guide

A. Prerequisites

  • Shopify Store - Any Shopify plan (Basic, Professional, etc.)
  • Basic Knowledge - Familiarity with Shopify admin interface
  • Optional - Code editor for advanced customizations (VS Code recommended)
  • Shopify CLI - For local development (optional but recommended)

B. Download the Theme

  1. Download the theme ZIP file from the source
  2. Extract the files to access the theme package
  3. Ensure the folder contains: config/, sections/, snippets/, etc.

C. Upload to Shopify

📝 Method 1: Shopify Admin (Manual Upload)
  1. Log in to your Shopify Admin
  2. Navigate to Online Store → Themes
  3. Click Add theme → Upload zip file
  4. Select the flowtheme-v1.0.0.zip file
  5. Wait for upload to complete
💻 Method 2: Shopify CLI (Recommended for Developers)
  1. Install Shopify CLI: npm install -g @shopify/cli @shopify/theme
  2. Navigate to your theme directory: cd flowtheme
  3. Connect to your store: shopify auth login
  4. Start development: shopify theme dev
  5. Open the local URL provided in terminal

D. Activate the Theme

  1. After uploading, locate the theme in your theme library
  2. Click Actions → Preview to test
  3. Once satisfied, click Actions → Publish
⚠️ Important

Do NOT delete your current live theme until you've confirmed the new theme works correctly!

Editing Code

  • Use Shopify Admin → Themes → Edit code
  • Or use Shopify CLI with your code editor
  • Files use Liquid templating language
  • CSS in assets/theme.css
  • JavaScript in assets/theme.js

Custom CSS

<!-- Add to theme.liquid before </head> --> <style> .my-custom-class { color: #ff0000; font-size: 18px; } </style>

Custom JavaScript

<!-- Add to theme.liquid before </body> --> <script> document.addEventListener('DOMContentLoaded', function() { console.log('FlowTheme loaded!'); }); </script>

🌐 Multi-Language Support

FlowTheme supports translations and multi-language stores through Shopify's built-in translation system.

Translating Content

  1. Go to Shopify Admin → Store Languages
  2. Add a new language or select existing
  3. Navigate to Online Store → Themes → Translate theme
  4. Translate each string displayed
  5. Save and publish changes

Translation Files

Theme strings are stored in locales/en.default.json. You can create additional locale files:

locales/ ├── en.default.json (English - default) ├── es.json (Spanish) ├── fr.json (French) ├── de.json (German) └── ja.json (Japanese)
💡 Tip

Use Shopify's built-in translation editor for the easiest experience - it handles all locale file updates automatically.

Adding App Scripts

  1. Go to Shopify Admin → Themes → Edit code
  2. Open layout/theme.liquid
  3. Paste app script before </body> tag

Troubleshooting App Conflicts

  • If an app doesn't display correctly, check for JavaScript errors in browser console
  • Some apps require adding their own section - look in Shopify's app block settings
  • Clear theme cache after adding new apps
  • Contact app support if issues persist

❓ FAQ

How do I update FlowTheme? ▼

Download the latest version from the source, then upload and publish it via Shopify Admin → Themes. Note: Customizations made directly to theme files may be overwritten during updates. For custom code, consider using Shopify CLI and Git for version control.

Can I use FlowTheme on multiple stores? ▼

Yes! FlowTheme is licensed under MIT License, which allows unlimited use on any number of Shopify stores. It's completely free for personal and commercial use.

Is FlowTheme compatible with Shopify's latest features? ▼

FlowTheme is built on Shopify 2.0 (Online Store 2.0) architecture, which is Shopify's current standard. It supports all modern features including JSON templates, app blocks, and dynamic data sources. As Shopify updates, we'll keep the theme updated.

How do I add a new language? ▼

Go to Shopify Admin → Store Languages → Add language. Then navigate to Online Store → Themes → Translate theme to translate all theme strings. You can also create locale JSON files directly in the locales/ folder.

Can I remove the "Powered by Shopify" footer? ▼

Yes, this is controlled in Shopify Admin → Settings → Store Details → Copyright. You can customize or remove this text. The theme does not add any additional branding.

How do I add a custom section? ▼

For developers: Create a new .liquid file in the sections/ folder, then register it in config/settings_schema.json. For non-developers: Use the Theme Editor to add any of the 26 built-in sections, or consider using a section-building app from Shopify App Store.

Does FlowTheme support RTL (Right-to-Left) languages? ▼

Basic RTL support is available. Enable it via Theme Editor → Theme Settings, or add RTL CSS to your custom stylesheet. Arabic and Hebrew languages will need additional styling adjustments.

How do I enable the wishlist feature? ▼

FlowTheme includes a wishlist template (page.wishlist.liquid). Assign it to a page via Shopify Admin → Pages, then link to it from your navigation or product cards. For full functionality, consider integrating a wishlist app.
